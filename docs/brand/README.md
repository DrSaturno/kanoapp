# Identidad visual Kano

La referencia recibida del cliente se conserva en `client-reference.png`. De allí se adoptan negro/grafito, blanco cálido y ámbar, además del tono deportivo condensado.

La interfaz usa temporalmente un wordmark tipográfico `KANO` porque la captura no contiene un archivo de logo aislado con calidad suficiente. Cuando el cliente entregue SVG/AI/EPS, debe sustituirse mediante un componente de marca, sin redibujar ni deformar el original.

Los estados de cobro mantienen sus cinco significados independientes de la marca: verde pagado, amarillo próximo, naranja parcial, rojo vencido y gris inactivo. Siempre incluyen texto e icono.
